## Topic framing

The image topic is interpreted as the three practical LLM application skills: RAG, AI agents, and model fine-tuning. The plan treats them as one engineering stack rather than three isolated topics:

- RAG answers, "What knowledge should the model see at inference time?"
- Agents answer, "What actions and control flow should surround the model?"
- Fine-tuning answers, "What behavior should move into model weights?"
