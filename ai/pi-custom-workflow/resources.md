## Evaluation Checklist for Any Resource

- Is it official, source-level, or community commentary?
- Does it explain the primitive being used, or only provide a copy-paste workflow?
- Does it require shell, filesystem, network, git push, secrets, or external API access?
- Can it be versioned and rolled back?
- What recurring model/API cost can it create?
